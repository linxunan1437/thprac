## 1. 口径

### 1.1 第 1 列记什么

- **格式**：`时间值/0x落点偏移` —— 十进制整数 + `/` + `0x` **大写**十六进制偏移，**无空格**。例：`3392/0xCDD4`、`68/0x472E`。
- **时间值**＝该 portion 体内 **`thPracParam.dlg == false` 那一支**的 `ECLWarp(<time>)` 入参（A 代口径：入口列记**时间值**，不记 sub 名）。
- **落点偏移**＝该关时间轴上**第一条 `time >= 时间值`** 的指令的**文件偏移**；与运行期 `tlInstr − pCode` 精确可比。
- **为什么偏移要进第 1 列**：th06 的时间轴上大量指令共享同一时间值、且 warp 值通常比落点时间小 0–60 帧 ⇒ **时间值单独不足以定位**，`(时间值, 落点偏移)` 才是「哪一条指令」。
