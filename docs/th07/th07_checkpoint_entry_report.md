## 1. 口径

### 1.1 第 1 列记什么

纯十进制整数（`540` / `1341`），**不写 `0x`、不写单位、不写 sub 名、不写 `count`**。语义＝`ECLTimeWarp(count, time)` 的 `time` 入参（`thprac_th07.cpp:891-898` 把它写进 `TL_0+8 … TL_{count-1}+8`，步长 `0x10`）。th07 运行期**不保留 sub 名**（sub 表只有指针），章节定位走**时间轴** ⇒ 入口列只能记时间值。

### 1.2 章节行 ↔ section 的对应

`portion` ↔ 记录名由 `mChapterSetup[8][2]`（`thprac_th07.cpp:411-420`）决定 —— `portion` 从 1 连续编号，前 `前半` 个 → `前半 #k`，其余 → `后半 #k`；`后半 == 0` 的关直接 `STn #k`。

## 3. boss 阶段部分已撤下（2026-10-27）

原文件关于 **boss 阶段**的内容已全部删除，**不作任何保留、也不作结论引用**，包括：

- 15 组「同时间多分节」与「副键＝`(SubN, 子内偏移)`」的推导；
- `ST4 BOSS1↔BOSS3`、`ST6` 十档、`ST7/ST8` NS/S 链等可分性判断；
- boss 阶段切换机制（`ins_144` / `ins_108` / `E+0x2B08` / HP 与倒计时）的解释；
- 监控两级判定（挑槽、`ip → SubN`、`seen` 累积、`thFakeShot` 作为判据）。

**撤下原因**：这些结论建立在「阶段＝sub 且可由 `ip` 唯一确定」的假设上；2026-10-27 的复查发现该假设不成立（引擎不按 HP 阈值分叉；同一 `sub` 可被多个切点复用；`ECLSetHealth` 覆盖的是 `call` 指令），已无法保证正确性。
