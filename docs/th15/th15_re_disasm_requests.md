# TH15 反编译/反汇编需求文档（供反编译组）

> 背景：thprac 需要在 TH15（东方绀珠传, Legacy of Lunatic Kingdom）中实现一个功能：
> **自机 miss / bomb 时，记录当时所在关卡序号；若处于 boss 战，则记录 boss 当前所处阶段。
> 记录按"一局游戏"分行落盘，每次游戏结束/重开另起一行。**
>
> 为把实现方案定死（读游戏内存 vs 自维护计数器），需要确认以下四处代码细节。
> 以下地址均为 thprac 已挂钩或已知的游戏静态基址（thprac 通过 `ingame_image_base` 重定位）。

---

## 1. Boss 当前阶段（最关键）

### 目标
在 miss/bomb 发生的瞬间，需要拿到"当前 boss 正处于第几个阶段（攻击）"。
理想情况：存在一个可直接读取的**内存地址（全局量或 boss 对象字段）**，存着当前 boss 的阶段/攻击序号。

### 需要确认的问题
1. 游戏在 boss 战中把"当前阶段 / 当前攻击序号"存在哪个内存地址？
   - 如果是全局量：给出绝对地址（如 `0x4E7480`）与取值语义（0 起还是 1 起？非 boss 战时的值？）。
   - 如果是 boss 对象字段：给出 boss 对象基址的获取方式（全局指针地址 + 偏移链）及字段偏移。
2. `0x4E73F8`（thprac 的 `th15_chapter_set` 钩子写入的地址，注释为"当前章节号"）：
   - 在**正常游玩**（非练习模式）时，这个地址是什么语义？
   - 道中 / boss 战中，它是否会随 boss 阶段推进而变化？
   - 它是否足以区分"道中 / 关底 boss 第 N 阶段"？取值范围与编码方式？
3. 是否存在独立的"boss 战斗进行中"标志位（便于区分道中与 boss 战）？给出地址与取值。

### 背景参考（thprac 已确认的邻近地址）
- `0x4E73F0`：当前关卡号（thprac IGI 已读，正常游玩 1~7，7 为 EX）。
- `0x4E7484`：本章节敌机总数；`0x4E7488`：本章节已击破数（thprac 已读）。
- `0x4E7404`：自机角色；`0x4E7410`：难度；`0x4E7450`：残机；`0x4E745C`：炸弹。

## 2. Boss 转阶段执行点

thprac 已有两个挂在 ECL 解释器上的钩子，疑似与 boss 阶段推进相关，需要其所在函数的反汇编以确认能否复用：

| 地址 | 长度 | thprac 现有注释 |
| --- | --- | --- |
| `0x42C738` | 4B | "SetNextPattern case 514" |
| `0x42B938` | 2B | "set boss mode case 512" |

### 需要确认的问题
1. 这两个地址所在函数的反汇编（含 case 512 / case 514 两个分支的完整代码）。
2. hook 命中时，`pCtx` 中哪些寄存器 / 栈参数携带**新阶段序号**？具体到：哪个寄存器/栈偏移，取值语义。
3. 这两个 ECL 指令是否**所有 boss（道中 boss + 关底 boss）每次换攻击时都会执行一遍**？
   - 是否存在某些 boss / 某些阶段（如符卡击破、非符阶段）不走这两条路径的情况？
4. 是否存在其它与 boss 阶段推进相关、更容易挂钩的执行点（例如显示符卡名、阶段号递增处）？

## 3. 游戏开始 / 结束判定

### 目标
- "一局开始"：开启新的一行记录。
- "一局结束"（残机耗尽 / 通关 / 退回主菜单）：收尾当前行并落盘。

### 需要确认的问题
1. `0x43E6EE`（thprac 的 `th15_game_start`，注释 "gamestart-bomb set"，现用于清零 miss/bomb 计数）：
   - 是**只在开局时触发一次**，还是**每关开始也触发**？
   - 若每关也触发，是否可用它做"重开/新一局"的边界？是否有更合适的"进入新一局"执行点？
2. 一局结束的各个路径，分别走到哪些代码地址：
   - **残机耗尽 → Game Over / Continue 界面**；
   - **通关（6 面 clear / EX clear）→ 结算画面**；
   - **游玩中退回主菜单 / 暂停退出**；
   - 各路径是否有一个统一可挂的地址？各给出具体地址与上下文（前几条指令即可）。
3. 若没有统一地址，给出"离开游戏态"的可观察内存标志（如自机指针 `PLAYER_PTR = 0x4E9BB8` 变为 0，或游戏状态全局量的取值变化），并说明哪些状态属于"一局中"、哪些属于"一局外"。

## 4. Miss / Bomb 执行点（复核现有钩子上下文）

thprac 现有两个计数钩子，需要确认挂钩点上下文，以便在回调里可靠读取关卡号与 boss 阶段：

| 地址 | 长度 | thprac 现有注释 |
| --- | --- | --- |
| `0x456398` | 5B | "life dec"（掉命） |
| `0x41497A` | 5B | "bomb dec"（扣雷） |

### 需要确认的问题
1. 这两个地址所在的函数反汇编（前后各若干条指令）。
2. hook 命中瞬间，读取 `0x4E73F0`（关卡号）是否可靠？
3. hook 命中瞬间，第 1 节找到的"boss 阶段"地址是否已是最新值？（即掉命/扣雷发生与阶段状态更新的先后关系）
4. 掉命路径中是否存在"自机无敌/受击判定已触发但残机尚未扣减"的先行执行点？如果有，是否更适合作为记录点？

## 5. ECL 脚本层面（可选 / 兜底）

> 本部分为**按需调查**，不是首要任务。请先完成第 1、2 节；仅在遇到以下场景时再深入脚本：
> 解释器反汇编未暴露干净的阶段内存地址（此时需自维护计数器 + 阶段映射），或需要佐证"所有 boss 阶段切换都走 case 514/512"。

### 需要确认的问题
1. 各关 boss 段（含道中 boss、关底 boss、EX boss、ST6 特殊 boss）的**阶段序列结构**：
   - 每场 boss 战共有几个阶段（非符/符卡），每阶段由哪些 ECL 指令驱动进入？
   - 是否所有阶段推进都经由 SetNextPattern（case 514）或 set boss mode（case 512）？有无例外路径？
2. 章节类 ECL 指令的语义：`0x43dd58`（thprac 的 `th15_chapter_set` 钩子）处理的章节跳转，其指令参数如何编码章节号？正常游玩时 `0x4E73F8` 的取值是否直接由该指令写入？

### thprac 侧已有的 ECL 结构参考（无需重复调查）
- `thprac_th15.cpp` 的 `THSectionPatch()`（约 `thprac_th15.cpp:1277` 起）已按关卡段落做细粒度 ECL 二进制改写，包含每关 boss 的"Set Health / Set Spell Ordinal / Change Nonspell / Spell Practice Jump"等指令偏移。
- `th_sections_cbt[7][2][14]` 表（练习模式非符/符卡段落编号）已含各关 boss 的阶段序号映射。
